# Практическое задание 2. Консольный поиск по Википедии

Консольное приложение на Java, которое ищет статьи в русской Википедии.
Пользователь вводит поисковый запрос, программа показывает список найденных статей
и открывает выбранную статью в браузере.
Готовые библиотеки для работы с Википедией не используются: запрос к API
формируется вручную, ответ разбирается с помощью Gson.

## Возможности

- Поиск статей по любому запросу, включая русские буквы, пробелы и спецсимволы
- Вывод нумерованного списка статей с заголовком и фрагментом текста
- Открытие выбранной статьи в браузере по её номеру
- Повторный поиск без перезапуска программы
- Обработка некорректного ввода и ошибок сети без аварийного завершения

## Этапы работы программы

| Этап                        | Класс                  | Что делает                                                   |
|-----------------------------|------------------------|--------------------------------------------------------------|
| 1. Считать ввод             | `ConsoleInput`         | читает запрос и номер статьи, проверяет ввод                 |
| 2. Сделать запрос к серверу | `WikipediaClient`      | кодирует запрос через `URLEncoder`, отправляет его в API     |
| 3. Распарсить ответ         | `SearchResponseParser` | превращает JSON в список статей с помощью Gson               |
| 4. Вывести результат        | `ResultPrinter`        | печатает список статей и сообщения пользователю              |
| 5. Открыть страницу         | `BrowserOpener`        | строит ссылку по `pageid` и открывает её через `Desktop`     |

Запрос к API:
```
https://ru.wikipedia.org/w/api.php?action=query&list=search&utf8=&format=json&srlimit=10&srsearch=<запрос>
```

Ссылка на статью:
```
https://ru.wikipedia.org/w/index.php?curid=<pageid>
```

## Обработка ошибок

| Ситуация                         | Реакция программы                                              |
|----------------------------------|----------------------------------------------------------------|
| Пустой запрос                    | просит ввести запрос ещё раз                                   |
| По запросу ничего не найдено     | сообщает об этом и предлагает новый поиск                      |
| Буквы вместо номера статьи       | просит ввести целое число                                      |
| Номер вне списка                 | сообщает допустимый диапазон                                   |
| `0` при выборе статьи            | возвращает к новому поиску                                     |
| `выход` или конец ввода (Ctrl+D) | завершает программу                                            |
| Нет интернета, таймаут           | сообщает об ошибке, можно повторить поиск                      |
| Сервер вернул ошибку             | показывает код ответа или текст ошибки API                     |
| Браузер не открылся              | выводит ссылку на статью, чтобы открыть её вручную             |
| Ошибка в файле настроек          | сообщает, какой параметр неверен, и завершает программу        |

## Настройки

Параметры вынесены в `src/main/resources/application.properties`,
чтобы менять их без правки кода:

| Параметр                  | Назначение                                  | Значение по умолчанию                          |
|---------------------------|---------------------------------------------|------------------------------------------------|
| `api.url`                 | адрес API Википедии                         | `https://ru.wikipedia.org/w/api.php`           |
| `article.url`             | начало ссылки на статью                     | `https://ru.wikipedia.org/w/index.php?curid=`  |
| `search.limit`            | сколько статей показывать                   | `10`                                           |
| `request.timeout.seconds` | сколько секунд ждать ответа сервера         | `10`                                           |
| `user.agent`              | как программа представляется Википедии      | название и ссылка на репозиторий               |

Например, чтобы искать в английской Википедии, достаточно заменить `ru` на `en`
в параметрах `api.url` и `article.url`.

## Технологии

- Java 27
- Maven
- Gson 2.13.2 — разбор JSON
- `java.net.http.HttpClient` — запросы к API
- `java.awt.Desktop` — открытие браузера

## Сборка и запуск

Требуется установленная JDK 27+ и Maven.

Рекомендуемый способ — открыть проект в IntelliJ IDEA и запустить класс `wikisearch.Main`.

Запуск из консоли:
```
mvn compile exec:java -Dexec.mainClass=wikisearch.Main
```

Программа читает ввод в кодировке UTF-8. В консоли IntelliJ IDEA русские запросы работают
корректно, а в стандартной консоли Windows (cmd, PowerShell) могут читаться неправильно.

## Структура проекта
```
src/main/java/wikisearch/
├── input/       ConsoleInput — чтение запроса и номера статьи
├── api/         WikipediaClient — запрос к API Википедии
├── parser/      SearchResponseParser — разбор JSON-ответа
├── output/      ResultPrinter — вывод результатов и сообщений
├── browser/     BrowserOpener — открытие статьи в браузере
├── app/         WikiSearchApp — главный цикл программы
├── config/      AppConfig — чтение файла настроек
├── model/       SearchResult — найденная статья
├── exception/   WikiSearchException — ошибка поиска
└── Main.java    точка входа: создаёт объекты и запускает приложение
src/main/resources/
└── application.properties   настройки приложения
```

- Каждый класс отвечает за один этап, `WikiSearchApp` только вызывает их по порядку
- Зависимости передаются через конструктор, `Main` собирает все объекты
- Ошибки сети, ответа сервера и браузера переводятся в `WikiSearchException`
  с понятным сообщением; главный цикл выводит его и продолжает работу

## Работа с репозиторием

- Ветка main содержит только проверенный код; прямые коммиты в неё не делаются
- Каждая задача ведётся в отдельной ветке (feature/..., fix/..., docs/...)
- Изменения попадают в main через Pull Request после ревью второго участника
- Найденные ошибки оформляются как Issue и закрываются Pull Request'ом с исправлением
- Сообщения коммитов оформляются так:
  feat:, fix:, docs:, chore:
